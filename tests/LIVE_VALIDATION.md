2026-10-10，用户在 Chrome 停用旧测试扩展并加载本仓库 `dist/extension`，重新观测连接后，通过官方 OpenCLI 1.8.8 的 `Page.setFileInput` 对仅本机的测试页面执行上传。

| 输入 | 结果 |
| --- | --- |
| 可见 file input | 文件名、37字节大小、完整内容、change 事件一次均通过 |
| 隐藏 file input | 同上，原 `display:none` 内联样式恢复通过 |

测试数据仅留在本机文件与浏览器页面，没有提交外网，没有操作平台草稿或发布。公开记录去除了 profile、账号、本机路径及原项目后台证据。

这是本仓库产物的真实上传测试，不是 GitHub Actions 运行结果。打包产物还需核对 ZIP 结构及与该上传函数的一致性；未宣称所有网站兼容。
